# Rogue Piece

Text/choice roguelike set in a generated pirate era. Devil Fruits and old seats of power are unclaimed again. The run decides who gets them.

## Run

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (usually `http://localhost:5173`).

Saves live in the browser via localStorage. Use **Development Save** for a separate sandbox that never overwrites normal slots.
